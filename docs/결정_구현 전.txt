

# 성능 / 환경 고정

Target machine : GTX 1060 Mobile
Target OS : Windows
Target scene : Intel Jungle Ruins, 60 fps
Resolution: 1920x1080 FHD
Executeable: FastJungle.exe
Quality : basic PBR, alpha-tested foliage, light/shadow
Concept : avoid generality, gain performance by fixed target

DX12 / DXC / SM 6.6
